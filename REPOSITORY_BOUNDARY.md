# ESCIE PUBLIC ↔ ESCIE CENTRAL BOUNDARY

EscieMusic owns the public ESCIE experience, public content contracts, and THE WORLD presentation/runtime. EscieCentral owns authenticated workspace operations, private media, agent execution, approvals, connectors, distribution state, and audit history.

## Non-interference rules

1. No cross-repository source imports.
2. No shared mutable localStorage contract.
3. No Central credentials, private tokens, or private media in the public repository.
4. Public canon remains owned by EscieMusic.
5. Central operational state remains owned by EscieCentral/Supabase.
6. Cross-system communication uses explicit API/connector contracts.
7. Public deployment and Central deployment remain independent.
