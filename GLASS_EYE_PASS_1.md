# GLASS EYE — PASS 1 OF 3

Status: OPTIMIZATION PASS 1 COMPLETE

## Core identity

GLASS EYE is the audience eye: the place where the visitor sees through the screen rather than being given an explanation of the universe.

The visitor can:

- see;
- hear;
- follow;
- miss;
- return.

The experience belongs to the visitor's journey.

## Pass 1 priorities

1. Preserve the audience-eye concept.
2. Keep the interface sparse and sensory.
3. Keep local viewer memory separate from ESCIE canon.
4. Keep EN / FR / ES available.
5. Keep the return-to-world path immediate.
6. Keep information optional rather than explanatory.
7. Never expose Central history as viewer memory.
8. Never turn Glass Eye into a public evidence dashboard.

## Local memory boundary

Glass Eye may remember the visitor's local path for their own session/device experience.

That memory is:

- local;
- private;
- non-canonical;
- not Central history;
- not evidence;
- not a public relationship.

Clearing it must not affect canonical ESCIE records.

## Interaction model

SEE WHAT I SAW:
provides an immediate sensory response.

FOLLOW MY THREAD:
lets the visitor continue their own path.

RETURN TO THE WORLD:
opens the public THE WORLD section and returns the visitor there.

INFO:
explains the Glass Eye concept only when requested.

The interface should not require the visitor to understand the system before using it.

## Participation boundary

If visitor contributions are offered, they remain submissions until reviewed and approved.

A submission is never canon merely because it was sent.

## Pass 1 acceptance criteria

- Glass Eye remains the audience-eye layer.
- Sensory experience comes before explanation.
- Local memory is explicitly non-canonical.
- Viewer memory never becomes Central history automatically.
- EN / FR / ES remain supported.
- Return-to-world navigation remains direct.
- No reality-classification labels appear.
- No forced puzzle/investigation behavior is introduced.
- No game or shop dependency is required.
- The section remains usable when no approved contribution/media exists.

Pass 2 will optimize sensory media, navigation, visual states and interaction depth.
