# GLASS EYE — REBUILD ARCHITECTURE

Status: PRIVATE DEVELOPMENT BRANCH / NOT RELEASED

Glass Eye is the audience eye of ESCIE: the visitor sees through the screen rather than receiving an explanation of the universe.

## Experience order
1. SEE — immediate sensory entry
2. HEAR — approved media and environmental signal
3. FOLLOW — visitor-controlled thread
4. MISS — ambiguity and incomplete information are intentional
5. RETURN — the visitor can leave and re-enter without losing their place

## System boundaries
### Viewer state
Local, private, non-canonical state. It may contain the visitor's local path, viewed items, dismissed prompts and temporary participation draft. Site-wide language selection belongs to the main ESCIE site, not Glass Eye.

### Canonical ESCIE content
Artist-approved public material only. Never created automatically from viewer activity.

### Participation
Uploads, comments and theories are submissions until explicitly reviewed/approved. Submission != canon.

### Media
Only approved public media is rendered. Empty states must be intentional, not filled with placeholders.

### Navigation
Glass Eye can return directly to THE WORLD and must not require the game, shop or Central.

## Primary modules
- experience — orchestrates the Glass Eye sequence
- media — approved sensory media
- memory — local viewer memory boundary
- participation — submissions and review states
- connections — visitor-facing relationships between public material
- accessibility — keyboard, touch, reduced motion, focus and labels
- visual — Glass Eye presentation only

Glass Eye does not maintain a separate language system or language toggle. The main ESCIE site language control already governs the public experience.

## What Glass Eye is not
- not a public evidence dashboard
- not Central
- not a conventional social feed
- not a forced puzzle
- not an ARG label
- not a replacement for the public world
- not dependent on EMPTYHELL

## Release rule
The development branch remains unreleased until Pass 3 regression, accessibility, responsive, media, participation-boundary and deployment checks are green.
