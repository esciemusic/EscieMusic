# ESCIE Pass 10 — Softened Authored Silhouette

Prototype-only typography pass. Production fonts remain unchanged.

## Why Pass 10

Pass 9 successfully removed the contour noise exposed in Pass 8, but its
straight-edged construction read too angular, techno, and pixel-like.

Pass 10 keeps the clean-silhouette discipline and changes the *geometry*:

- longer, smoother curves on C / G / O / R / S;
- fewer hard polygonal transitions;
- controlled terminal softness without ornamental serifs;
- human asymmetry remains structural, not damaged;
- tall/narrow Gothic-medieval authority remains the dominant proportion;
- SIGNAL remains the cleaner operational state;
- SCRIPT remains a separate handwritten state;
- French/English coverage is inherited from the existing builder;
- no texture, glitch, distress, or decorative horror.

## Anchor set

A / C / E / G / I / M / O / R / S / T

## Acceptance gate

Pass only if:

1. contours remain solid at desktop size;
2. C / G / O / R / S read as smooth authored curves, not polygonal rings;
3. ESCIE feels human-authored rather than techno/pixel;
4. tall/narrow authority survives;
5. SIGNAL is visibly calmer than ESCIE;
6. phone-scale text remains readable;
7. French accents remain clean;
8. no stock Gothic, fantasy-horror decoration, glitch, distress, or texture appears.

Production promotion remains locked until actual desktop + 390px phone specimens
are rendered and visually reviewed.
