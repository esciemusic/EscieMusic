# ESCIE Pass 9 — Clean Silhouette

Prototype-only typography pass. Production fonts remain unchanged.

## Objective

Pass 8 exposed contour noise caused by intersecting stroke fragments and overly complex geometry. Pass 9 removes that source of failure.

- Filled silhouettes instead of overlapping curve/stroke fragments for the signature anchors.
- Preserve tall, narrow Gothic/medieval authority.
- Preserve restrained human asymmetry.
- Keep ESCIE and SIGNAL related without introducing glitch, distress, or techno decoration.
- Keep French/English glyph coverage inherited from the existing builder.
- Keep production typography locked until a rendered desktop + 390px phone specimen is reviewed.

## Anchor set

A / C / E / G / I / M / O / R / S / T

## Acceptance gate

Pass only if:

1. contours remain solid at desktop size;
2. no speckled, broken, or self-intersecting edges appear;
3. ESCIE reads immediately;
4. SIGNAL remains operational and restrained;
5. phone-scale text remains readable;
6. the result feels authored rather than stock Gothic, pixel, or techno;
7. French accents remain clean.

This pass is not a production promotion.
