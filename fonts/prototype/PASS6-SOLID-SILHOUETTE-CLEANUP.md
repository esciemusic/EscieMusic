# ESCIE Font Pass 6 — Solid Silhouette Cleanup

## Finding

The Pass-5 specimen is useful, but it fails the most important visual test: the identity anchors are too mechanically distressed and several overlapping vector primitives create unstable-looking edges. The result reads like a generated glitch font instead of an authored typeface.

## Pass 6 objective

Make the letterforms themselves distinctive while making their silhouettes **solid, intentional, and readable**.

### Rules

- No fake damage.
- No texture or glitch artifacts inside the glyphs.
- No reliance on CSS effects.
- Use one strong outer silhouette plus deliberate counters wherever possible.
- Preserve the narrow architectural proportion.
- Keep asymmetry structural, not noisy.
- Signature anchors remain A / C / E / G / M / O / R / S / T.
- SIGNAL must be cleaner than ESCIE.
- SCRIPT remains a separate handwritten state.
- French glyphs must inherit the same construction cleanly.

### Anchor corrections

- **A:** one outer silhouette + controlled triangular counter; compressed apex.
- **C:** one clean open architectural oval with unequal terminals.
- **E:** three-arm structure with a genuinely shorter middle arm.
- **G:** C-family silhouette plus one proprietary internal bar.
- **M:** strong verticals with a deep central descent; no overlapping stroke noise.
- **O:** narrow oval with a stable counter.
- **R:** solid bowl with a decisive bowl-to-leg transition.
- **S:** asymmetrical upper/lower masses without broken-looking seams.
- **T:** heavy cap with narrow stem.

## Rejection rule

If a specimen looks like a generic gothic/tech font, it fails.

If it looks like a glitch font because of construction artifacts, it fails.

If it becomes so unusual that Montréal, ESCIE, navigation, or French text stop being readable at phone scale, it fails.

The target is **recognizable authorship + usable typography**, not visual distortion.

Production remains locked.
