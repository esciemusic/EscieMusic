# ESCIE Font Letterform Prototypes

This directory contains the first original letterform prototypes for the ESCIE family.

## Three faces

- **ESCIE** — identity / titles / section names. Dense, gothic, architectural, damaged rather than fantasy.
- **ESCIE SIGNAL** — navigation / evidence / metadata. Industrial, geometric, operational and phone-readable.
- **ESCIE SCRIPT** — visitor traces / intimate notes. Human, imperfect, handwritten and restrained.

## Important

These are **prototype binaries**, not yet production typography.

They are intentionally not wired into the public site until the letterforms pass:
1. identity test — recognizable as ESCIE without the name;
2. family test — all three faces feel related;
3. readability test — phone and desktop;
4. glyph coverage test — required punctuation, French accents and release metadata;
5. provenance/licensing test.

No external font service is used.

The public site continues using its safe fallback stack until the final faces are approved.
