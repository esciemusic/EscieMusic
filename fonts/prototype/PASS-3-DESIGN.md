# ESCIE Typography Pass 3 — Script + Signature Glyph Review

## Focus

Pass 3 concentrates on the two areas that still prevent the family from feeling fully authored:

1. ESCIE signature glyph construction.
2. ESCIE SCRIPT lowercase handwriting.

## SCRIPT

The SCRIPT pass now has a dedicated lowercase construction rather than deriving lowercase from the display face.

Target qualities:
- human pressure
- uneven but controlled rhythm
- connected-feel movement
- narrow vertical family proportions
- intimate rather than romantic
- readable at visitor-trace sizes

The pass is deliberately isolated as a prototype. It is not yet a production font.

## ESCIE signature glyphs

The next ESCIE specimen review should pay special attention to:

- A — distinctive apex and counter
- E — interrupted horizontal structure
- G — controlled opening and internal bar
- R — strong bowl-to-leg transition
- S — asymmetrical tension
- M — architectural central descent
- T — heavy top / narrow stem
- C/O — damaged-but-controlled openings

These glyphs carry more identity than adding more decorative effects.

## Family rule

The three faces should share:
- vertical proportions
- terminal logic
- spacing discipline
- counter philosophy

They should differ by state:
- ESCIE = identity
- SIGNAL = operation
- SCRIPT = intimacy

## Gate

No production merge yet.

Next review is a specimen-based comparison at desktop and phone sizes. The question is not whether each font looks attractive. The question is whether all three immediately feel like different states of the same ESCIE system.
